Send to PC

One-gesture mode: iOS Shortcuts (works inside any app)

iOS lets only Apple's own Universal Clipboard change the clipboard in the background, so no app or web page can make this fully automatic. Two Shortcuts get it down to one gesture (Back Tap, Action button, Lock Screen or Share sheet), with no need to open this page.

Shortcut 1 · “Get from PC” (puts the latest PC copy into the iPhone clipboard)
  1. Get Contents of URL — paste this URL, Method GET
    …
  2. Copy to Clipboard — input: Contents of URL
  3. Show Notification — “Copied from PC” (optional)
Shortcut 2 · “Send to PC” (sends the iPhone clipboard, text or picture, to the PC clipboard)
  1. Get Clipboard
  2. Get Images from Input — input: Clipboard
  3. Get Contents of URL — paste this URL, then tap Show More: Method POST, Request Body Form. Add two fields: File named image = Images, and Text named text = Clipboard.
    …

Then: Settings → Accessibility → Touch → Back Tap → Double Tap = “Get from PC”, Triple Tap = “Send to PC”. Copy on the PC, double-tap the back of the phone, paste anywhere. Works for text and images.
